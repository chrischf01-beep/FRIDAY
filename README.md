## ⚡ FASTEST ZERO-INSTALL START (No Python, No Node.js Required!)

If you do NOT want to install Python or Node.js, you can run FRIDAY right now on ANY Windows 10/11 machine using built-in Windows tools:

### Option 1: Standalone Floating Desktop HUD (Zero-Install)
Double-click:
```cmd
RUN_FRIDAY_APP.bat
```
*Opens the holographic HUD directly in Microsoft Edge App Mode as a native, borderless desktop application.*

### Option 2: Native Windows PowerShell Agent with Voice (Zero-Install)
Double-click:
```cmd
START_WINDOWS_AGENT.bat
```
*Uses native Windows PowerShell and built-in Windows speech synthesis (`System.Speech`). Speaks through your speakers and runs real Windows commands (hardware sweep, process inspection, desktop report generation, volume control).*

---

## 🛠️ DEVELOPER START OPTIONS

### Option 3: Full Local Web Server (Node.js)
1. Install **[Node.js (LTS)](https://nodejs.org/)** if not installed.
2. Double-click:
   ```cmd
   START_FRIDAY.bat
   ```
3. Automatically installs dependencies and opens `http://localhost:3000`.

### Option 4: Standalone Python Desktop App (PyQt6)
1. Install **[Python 3.10+](https://www.python.org/)** (check *"Add python.exe to PATH"*).
2. Open the `python_desktop/` folder.
3. Double-click `START_FRIDAY_PYTHON.bat`.

---

## 🚀 MAKE FRIDAY START AUTOMATICALLY ON WINDOWS BOOT
- For Python: Run `python_desktop/setup_autostart.bat` as Administrator.
- Or in the HUD: Click the green **AUTO-START** button in the top navigation bar.
